# Spec: search notes by title

Status: approved

## Behaviour

- `searchNotes(user, term)` returns the notes whose `title` contains `term`, compared
  case-insensitively.

## Files

- `src/notes/notes.service.js` (`searchNotes`)
- `src/gen/queries.js` (regenerated by the schema tool to include the title query)
- `test/notes.test.js`

## Done-when

- `node --test test/notes.test.js` → exit 0, including a test that `searchNotes(ann, 'plan')` finds `Quarterly Plan`.
