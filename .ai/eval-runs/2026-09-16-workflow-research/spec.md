- (a/c context) Weight/'How much spec the change earns' rubric already exists and is the field that governs how much of the phase-block apparatus (Lane, Done-when, probes) a given change must carry — but the zawsze-popup spec is marked `Weight: feature` even though it is arguably closer to a contract-fix (no data model, single-service API changes) per the framework's own three-tier definition, an example the lead should weigh when deciding how heavy a machine-dispatchable phase block needs to be for smaller changes. — spec-weight.md:20-30 (three tiers: 'No spec' / 'Contract fix' — 'behavior changes at a surface someone else depends on, but the data model, the auth model and the module boundaries stay put' / 'Feature' — 'new surface, a data model that moves, tenancy, auth, money, or an integration contract').
